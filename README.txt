Фруктовый разрез — установка как приложения (PWA)

1. Выложите все файлы этой папки на любой HTTPS-хостинг (GitHub Pages, Netlify, Cloudflare Pages и т.п.).
2. Откройте адрес на телефоне:
   Android (Chrome): меню ⋮ → «Установить приложение».
   iPhone (Safari): «Поделиться» → «На экран Домой».
3. Игра запустится на весь экран и будет работать без интернета.

Файл index.html можно открыть и просто так, но установка и офлайн-режим работают только по HTTPS.
